# Module replacement

The Terrum files in this folder form examples for compiling providers and
consumers, replacing a compatible provider, rejecting an incompatible one,
and exercising token, range, and wide-value entries. Several sources are
library or consumer components without `Main`; they require the composition
shown in the implementation guide.

Follow the exact inputs, exports, and runtime policy in the
[semantic modules guide](../../docs/implementation/modules.md). Private
module artifacts are not standard TRRM interchange. See the
[sample catalog](../../docs/samples.md) for the broader support boundary.
