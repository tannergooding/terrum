# Calculator

`calculator.terrum` is a target-language design example, not a currently
executable compiler sample. It describes checked `int32` calculations and
conditional initialization of a result, including rejection of Unicode
digit/operator lookalikes rather than silently normalizing them.

Read the source against the
[language contracts](../../docs/specs/language-contracts.md) and the
[sample catalog](../../docs/samples.md). Its intended behavior is not
evidence that the required text/input APIs are implemented.
