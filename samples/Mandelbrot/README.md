# Mandelbrot

`mandelbrot.terrum` is a target-language design example for strict `float32`
arithmetic, explicit conversions, and PBM output. It checks dimensions and
bounds each point after 64 updates; it does not prove set membership.

The source is not an executable compiler sample. See the
[sample catalog](../../docs/samples.md) and
[implementation inventory](../../docs/implementation.md) for the support
boundary.
