# Hello world

This folder contains two target-language design examples:

- `hello-world.terrum` describes a `void Main` text-output program.
- `hello-async.terrum` sketches asynchronous entry, rooted arguments, and
  cleanup through completion.

Neither file is evidence of a currently supported text or async runtime. See
the [sample catalog](../../docs/samples.md) and
[implementation inventory](../../docs/implementation.md).
