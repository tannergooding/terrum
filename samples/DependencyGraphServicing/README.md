# Dependency-graph servicing

This folder contains leaf, middle, and consumer sources for native dependency
graphs, including owning exports, scoped views, and private managed
implementations behind handle-free public values. Individual files are
components in documented compositions, not a flat collection of executables.

Follow the selected providers, exports, policies, and expected results in the
[native graphs guide](../../docs/implementation/native-graph.md). See the
[sample catalog](../../docs/samples.md) for the compiler support boundary.
